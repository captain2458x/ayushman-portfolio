IoT Health Monitor

Overview: This project is part of Solution Squads (Team 9). The IoT Health Monitor, also called CardioGuard, is a wearable device that continuously tracks patient vitals such as ECG, heart rate (BPM), and SpO₂. It integrates low-cost sensors with an ESP8266 microcontroller and sends real-time data to the ThingSpeak IoT Cloud. Alerts are pushed instantly through the Telegram Bot API.

Key Features

  • Real-time ECG and heart rate monitoring (AD8232 + MAX30102)
  • ESP8266 Wi-Fi based IoT data transmission
  • ThingSpeak dashboard for vitals visualization
  • Instant alerts to patients, families, and doctors via Telegram
  • Prototype tested under Kalam Pragati MakeX Internship 2025

Tools & Technologies

  • Hardware: ESP8266 (NodeMCU), MAX30102, AD8232 ECG Sensor
  • Software: Arduino IDE, ThingSpeak Cloud, Telegram Bot API
  • Languages: Embedded C/C++
