CardioGuard – Real-Time Heart Monitoring & Alert System

Developed CardioGuard, a real-time wearable heart monitoring system designed to reduce sudden cardiac deaths by enabling continuous ECG monitoring and automated emergency alerts.

📌 Key Features:

Wearable ECG & heart-rate monitoring using AD8232 and MAX30102 sensors

IoT-enabled dashboards for patients, families, doctors, ambulances, and hospitals

Real-time alerts via Telegram bot & cloud integration (ThingSpeak)

Location tracking and pre-hospital notifications to save golden minutes

Figma UI prototype designed for multiple stakeholders:

Patient App → vitals, SOS button, history logs

Family Member App → live data + instant alerts with location map

Doctor Dashboard → real-time ECG view, patient list, emergency accept/decline

Ambulance Dashboard → live patient data + GPS navigation + pre-hospital alert
